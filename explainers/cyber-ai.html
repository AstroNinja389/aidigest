AI and computer security

The short version: software has mistakes in it, and some mistakes let attackers in. AI is getting good at finding those mistakes, which helps both the people fixing them and the people exploiting them.

What a vulnerability is

A vulnerability is an overlooked flaw in a program, like an unlocked window in a house. Security experts spend their days hunting for such flaws so they can be fixed before attackers find them.

Why AI changes the picture

Finding flaws means reading enormous amounts of code and trying many things. That is the kind of patient, repetitive work AI can do quickly. The same skill that lets a defender find and fix a flaw would let an attacker find and use it.

Dual use

Researchers call this "dual use": one tool, two possible purposes. It is why companies that release security-focused AI usually say who it is for and how access is controlled.
