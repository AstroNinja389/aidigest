Inside AI · Lesson 3 of 5

Why ideas share neurons

The short version: a model has to keep track of far more ideas than it has neurons, so it packs ideas in by using combinations of neurons, rather than one neuron each. Researchers call this superposition.

A piano analogy

A piano has 88 keys but can play a vast number of different chords. If each idea needed its own key, you would run out quickly. If each idea is a pattern of keys pressed together, you can fit many more.

The AI seems to do something like this. An idea is not one neuron lighting up. It is a particular pattern across many neurons. And each neuron takes part in many patterns, which is exactly why a single neuron looks like a mixture.

What it costs

Packing ideas this way causes some interference, like faint extra notes. The network can live with that because most ideas are rare. The word "Paris" and the concept of a chemical formula are seldom needed at the same moment, so their patterns rarely collide.

How sure are we?

This is a hypothesis. In 2022, Anthropic researchers showed that small, simplified networks really do behave this way when pushed to fit many ideas into few neurons (the "toy models" study). Evidence about the giant real models is more indirect. It is a leading explanation, not a settled fact.
